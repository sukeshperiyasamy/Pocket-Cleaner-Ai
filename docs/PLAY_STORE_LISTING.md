### Full Description (Limit: 4000 characters)
```text
Take back control of your device storage with a truly private, on-device AI assistant. Offline AI Phone Assistant gives you deep insights into your media storage, memory pressure, and large files without sending a single byte of your personal data to the cloud.

🧠 100% ON-DEVICE AI ASSISTANT
• Powered by local on-device language models (llama.rn) running directly on your phone's processor.
• Ask natural questions about your storage, large media files, screenshots, and system memory.
• Strict Grounded Truth: The assistant uses real Android system data and never hallucinates numbers or invents file statistics.
• Zero internet required: Works completely offline, even in Airplane mode.

📊 DEEP STORAGE ANALYZER
• Scans and categorizes your accessible storage into Images, Videos, Audio, and custom folders.
• Instantly surface space hogs: Filter large files by size (10 MB, 50 MB, 100 MB, 500 MB+).
• Find old screenshots and screen recordings cluttering your gallery.
• Storage Access Framework (SAF) integration for deep custom folder inspection.

🔒 SAFE, USER-CONFIRMED CLEANUP
• Your files are sacred: The AI assistant NEVER has permission to delete files on its own.
• Strict two-step deletion confirmation: Every cleanup action requires manual user review and explicit approval.
• Clear preview modals display exact file names, sizes, and total space to be freed before deletion.

⚡ HONEST ANDROID MEMORY TELEMETRY
• Real Android RAM reporting queried directly via ActivityManager and Linux kernel metrics.
• No fake "RAM Cleaners" or snake-oil speed boosters. We educate you on how Android's Low Memory Killer (LMK) actually handles cached background apps to preserve battery life.

🛡️ PRIVACY FIRST — ZERO TELEMETRY
• No cloud servers.
• No user tracking or analytics SDKs.
• No advertisements.
• No account creation or login required.
• All processing happens locally on your hardware.

Permissions Explained:
• Photos and Videos (READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIO): Required exclusively for indexing your local media library, displaying storage category totals, and identifying large candidate files for cleanup.
• Storage Access Framework: Allows you to selectively authorize custom directories for deep storage analysis without granting broad "All Files Access".

Requirements:
• Android 7.0 (API 24) or higher (optimized for Android 13, 14, 15, and 16).
• For on-device LLM inference, 4 GB+ RAM is recommended.
```
